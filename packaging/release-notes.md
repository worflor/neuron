Windows 10/11 (x86_64). The installer and portable ZIP include the tray app and CLI. The binaries are unsigned. Verify downloads with `SHA256SUMS.txt`; `SOURCE.txt` records the source commit.

{notes}

## Install

Use the installer, or unpack the portable ZIP into a writable folder and run `neuron-app.exe`. From here on, neuron offers each new release itself.

Still the Windows beta. [Feature status and platform limits](https://github.com/worflor/neuron/blob/{tag}/docs/STATUS.md).
